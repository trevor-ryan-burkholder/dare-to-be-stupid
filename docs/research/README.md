# Research records

Files in this directory record external ideas, measurements, adopted proposals, and explicit
rejections. Appearance in a research file does not make a proposal part of the specification or
live plan.

The headings in `BORROWED.md` are chronological intake decisions and may use historical phrases
such as “take it.” Read its current-disposition section before the body; only `DESIGN.md` and
`PLAN.md` can make an idea current.

`ECOSYSTEM-REVIEW-2026-08-16.md` is the current independent comparison ledger for vendor
capabilities, active agent systems, durable runtimes, and reliability research. Its HARVESTED,
ALREADY COVERED, REJECTED, PARKED, and OPEN QUESTION labels prevent later reviewers from promoting
interesting mechanisms without their admission evidence.

Accepted requirements belong in `DESIGN.md`; implementation work belongs in `PLAN.md`.
